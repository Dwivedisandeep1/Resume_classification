# Resume Classification

An NLP machine learning project for classifying resumes into predefined categories based on their textual content.

## Project Objective

Transform unstructured resume text into machine-learning features and build a classifier capable of assigning resumes to relevant categories.

## Workflow

- Text extraction / dataset preparation
- Text cleaning
- Tokenization and normalization
- Feature extraction
- Model training
- Classification evaluation
- Error analysis

## Technologies

- Python
- Pandas
- Scikit-learn
- NLP techniques
- Jupyter Notebook

## Project Status

NLP portfolio project. The repository will be consolidated with the most useful work from related resume-classification repositories as part of the GitHub cleanup.
